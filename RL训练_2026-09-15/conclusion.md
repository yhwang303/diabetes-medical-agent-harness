# 本轮结论与原因

结论对象是本轮产生的权重及证据，不是断言Loop永远不能用于RL。

当前不能把本轮权重作为大项目中生成个体化基础输注建议的RL部分。实际训练完成的是RL-DITR路线的患者模型前置组件fR/fT/fP；策略、价值学习和多步规划没有在失败的患者模型上继续优化，不能宣称完整RL策略已经训练完成。

## 最终实测摘要

两组成功训练都遍历了全部225名患者、1,653,421个起点，各一个完整epoch。全量validation为55人、424,866个起点，其中连续30/60分钟有效起点分别166,866和89,186。

- A02低学习率绝对输出：30/60分钟RMSE 1.0234 / 1.7208 mmol/L。
- A03残差输出：30/60分钟RMSE 0.9973 / 1.6775 mmol/L。
- 相同起点的恒值基线：1.3812 / 2.2369；线性趋势：1.5738 / 3.1433。
- 固定历史增加1 U/h：A02/A03的60分钟血糖变化中位数分别 +0.1757 / +0.1829 mmol/L，预测下降比例仅7.92% / 3.24%。
- 较小+0.1 U/h、51患者1,557个连续60分钟合格历史：A02/A03预测下降比例仅10.34% / 2.50%，变化中位数 +0.0151 / +0.0164 mmol/L。两组均未通过动作研究screen。

60分钟验证中79,683个片段实际保持恒定基础率；A03在此子集RMSE 1.6979，仍低于恒值基线2.2888。因此不能把全部拟合改善归为后续变化动作带来的信息，异常剂量方向的确切成因仍未被本轮实验证明。

在另一个固定1,557起点的输入诊断中，A03隐藏过去food/exercise后60分钟RMSE从1.7948变为1.8111，A02则从1.8079变为1.7931，影响方向不一致。exercise有记录的诊断样本仅37个。这说明不能声称本轮已证明新增特征有稳定收益；特征确已参与输入，数据量全部保留，需专门的重新训练消融与更可靠事件记录评价。

## 已经解决的环节

1. 数据与算力不是本轮开工阻塞：AutoDL RTX 4090真实训练成功，专用虚拟环境可用。Loop训练225人、1,653,421个起点全部保留；food/exercise作为带mask的稀疏历史特征进入72×22输入，没有要求模态齐全，也没有减少训练集。
2. 管线v2使用同一患者划分、资格索引及train-only归一化。封存测试与demo患者表没有上传、没有参与调参。所有训练失败、参数改变、完整/不完整epoch分开列出。
3. 降低学习率后，历史给定动作的血糖拟合恢复。这排除了“完全无法在这些数据上训练模型”的说法，但不能证明模型学到了可干预的生理动力学。

## 为什么仍不能放入RL给药链路

最直接的失败证据是：固定同一历史，增加候选基础输注，本轮选中权重常给出血糖上升的响应。较小的+0.1 U/h扰动复核也没有消除此问题。具体数值以第4节各权重实际输出为准。这不是药效估计；它是让模型充当策略环境前必须解释的异常。直接在这种环境中最大化奖励，策略可能利用错误的剂量关系。

这里的30/60分钟预测，模型已知日志中的后续真实基础率，而Last/线性基线只看起点历史。Loop控制器又会根据随后血糖调整剂量。因此较好RMSE只说明回顾性动作条件拟合，不能证明在线预测能力，更不能说明“换一个剂量后会发生什么”。恒定日志动作片段也只是回顾性筛选，不能解除混杂。

## 卡在数据、方法还是训练

- 数据边界：观察性闭环数据中，血糖升高会触发更多胰岛素；这种反馈相关性与胰岛素降低血糖的干预作用不能直接等同。food/exercise稀疏且录入可得时间不完整；本轮全部保留它们，但不能把未记录解释为没有事件。尚未证明相同病人/状态下候选剂量有足够支持，也未证明无未测混杂。
- 方法边界：当前transition只接收初始历史和候选未来basal。未来bolus、餐食、运动没有独立、可审计的情景生成定义；这些共同干预影响目标血糖。仅把过去food/exercise加进特征，不能独自解决未知未来事件和反事实辨识。
- 训练边界：本轮做了烟测、论文式绝对输出尝试、低学习率和残差输出对照。成功组各完成一个完整epoch；这不是充分收敛、多随机种子或穷尽超参搜索的证据。A01的非有限评价现场未保存，根因未定；后续数值修复有效运行，不能反推已查明A01根因。

因此，证据支持“本轮权重不可用于RL给药”，不支持“数据集彻底没用”或“单纯多训练几轮就能解决”。继续降低预测误差，和识别可信的剂量响应，是两个需要分别验证的问题。

## 下一轮应优先解决什么

保留当前全量数据和22维输入。先补齐未来共同干预/可得性定义，分清可记录的情景、未知事件和必须弃权的情况；随后在明确动作支持域内检验剂量响应与延迟，并用独立的公开生理仿真或其他独立证据做对照。不能通过强行规定输出单调、静默删样本或仅看自身模型内奖励来制造通过。

只有患者模型的适用域和动作后果通过独立验证后，才值得继续论文的历史监督、模型式策略目标与规划，并在独立环境比较基线。进入Harness还要完成真实来源/动作合同、独立预测器F及训练重叠审核、受控worker、双模型证据与安全发布闸门。当前产品TODO的M02a/M02继续未完成。

## 可交付与不可交付

可交付：经过核查的稀疏多模态训练输入、真实GPU训练代码、每次实际配置/源码/日志/权重、预测与动作诊断、失败证据、可复跑入口。
