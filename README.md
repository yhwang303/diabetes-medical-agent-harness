## 代码范围

当前部署选择固定上述模型；本轮研究源码和未采用候选作为审计记录单独保留。所选模型，不启用额外低糖罚分或执行层暂停。既有仓库中的Loop预处理、H02历史编码器、配对仿真和外部基线代码作为依赖保留。该版本目录含实际训练、推理、评价和报告生成代码，以及对应配置与证据摘要；不把内部开发变体当成正文外部对照。

模型权重、患者级Loop数据、CUDA依赖二进制和凭据不放入Git。现成权重的准确SHA256在版本文件中；本地保留完整研究推理恢复包`RL_DSENet_2026-09-17/delivery/DSENet_RL_single_seed_model.tar.gz`。没有权重时须按文档训练，只有源码不等于已经在新机器恢复了数值结果。

## 证据边界

这些是公开数据/公开仿真的研究结果，不是患者给药或产品准入证明。历史表中本方法为 L+S、外部离线方法为 L；当前表为外部方法补充了共享仿真数据，但表示、先验、训练目标、预算和调参史仍不同。当前协议更透明，不能称严格同条件算法 SOTA。单 seed、已知虚拟成人、低糖漏报与长时间低糖、部分基线严重失稳等限制必须保留。详见当前报告。Core/Harness产品边界未因研究结果改变。
