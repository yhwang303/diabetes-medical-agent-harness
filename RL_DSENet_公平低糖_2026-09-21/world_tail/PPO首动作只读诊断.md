# PPO 首动作变化：只读诊断

从正式PPO训练的160条轨迹，各等距取62个有完整48步实际未来的起点，共9920个观测状态。未按未来结果抽样；没有新增训练、仿真或候选。未访问确认集文件。

每条轨迹的persistent anchor由原训练环境NumPy2.4.6、首个控制前历史的上一时段实际basal按原公式重建。没有以当前rate替代anchor。预测读取旧D05冻结context/reference、rate及此anchor，未来CGM仅用于分组。physical映射直接调用原ppo_worker.physical：hold类取max、再与减量/加量类比较；该样本上与原7类argmax的首动作映射差异为0。

| 同一观测状态上的动作变化 | PPO02 | PPO04 | PPO08 |
|---|---:|---:|---:|
| 全部9920状态：变化数/比例 |315 / 3.18%|188 / 1.90%|149 / 1.50%|
| 比D06减少首剂量的状态 |313|183|86|
| 比D06增加首剂量的状态 |2|5|63|
| 实际未来60min CGM<70子集510状态：变化数 |6|11|11|
| 上述子集：减少/增加 |4 / 2|8 / 3|10 / 1|
| 实际未来60min CGM<54子集143状态：变化数 |1|1|3|
| 上述严重低糖子集：减少/增加 |1 / 0|1 / 0|3 / 0|

**这支持“PPO实际部署首动作变化很小”的描述。** PPO08在全部观测上98.50%的首动作与原actor相同；严重低糖关联子集也只改变3/143。物理动作概率分布的平均total variation分别为2.03%、1.48%、1.27%，表明概率本身也仅有小幅迁移，而非只是argmax掩盖巨大概率变化。

严重低糖关联子集里，原D06在相同观测上已经有125/143（87.41%）选择现有动作集合的减量档（anchor−0.25 U/h）；PPO08为128/143。该结果说明进一步改进不能单靠期待同一状态下大量翻转首动作。但是它不证明更早减量无效、不证明更宽动作集合必然有效，也不证明现动作下低糖不可避免。

**因果边界：** 未来低糖标签来自实际生成这些训练轨迹的随机PPO行为策略；没有从每个状态分别执行四个候选、模拟其后果。因此这是同状态策略变化与已观测结局的关联分析，不是候选反事实效果，也不是独立泛化评测。9920状态相互相关，不能当9920独立患者。

证据位于`checks/actor_diagnostic/`：抽样manifest、160轨迹及来源hash、selection.npz、四模型checkpoint hash、predictions.npz、result.json。抽样合同位于`configs/actor_diagnostic.json`；所有模型均只读取，没有更新。
