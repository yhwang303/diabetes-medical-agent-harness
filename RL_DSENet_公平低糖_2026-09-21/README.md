# DSENet RL 当前确认结果与复现入口

截至 2026-10-03，采用 2026-09-21 的冻结新场景确认结果作为主要研究汇报：TIR **95.61 ± 6.08%**、TBR70 **2.43 ± 4.88%**、TBR54 **0.86 ± 2.59%**。模型仍为原 P03 + D05 + D06，训练 seed 260915，未换权重。原 97.08 / 1.55 / 0.57 是已曝光的历史开发场景结果。

## 这里更新了什么

- 评测场景 seed 从开发用 91701/91702 换为预先冻结的 92111/92112；仍是 10 位已知成人仿真患者，每人三种餐时 bolus 比例和两个场景，共 60 条轨迹。
- 外部方法原生动作不再统一裁剪到 anchor ±0.25 U/h；我方模型自身的有限候选范围保持不变。另列共同 CGM 减量处理面板，不能把其效果全部归于模型。
- FQL、ReBRAC、LOM 实现顺序或更新相位修复后重训；八个外部方法补充共享仿真数据。记录相同来源不代表表示、目标、预算和调参史相同。
- 两面板、十方法共 1200 条轨迹完成。六个我方改进候选全部未通过预注册联合不退步标准，保留旧模型。

这是评测与披露流程的改进，不证明模型更强、所有基线已充分调优或临床安全。部分基线严重失稳；失败的未知尾部不能当作正常完成，也不能把观察前缀的低糖指标直接排第一。
