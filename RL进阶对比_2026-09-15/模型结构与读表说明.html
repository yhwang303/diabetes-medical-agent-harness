2. 为什么策略主表不用血糖MSE

指标测量什么用途
TIR ↑血糖70–180 mg/dL的时间比例本次闭环策略的主要效果指标
TBR70 / TBR54 ↓血糖低于70 / 54 mg/dL的时间比例检验低血糖代价，不能只追求高TIR
Mean risk ↓对每个血糖值计算下文risk函数，再对时间取平均高低血糖综合风险诊断，不是MSE
终止失败数 ↓模拟器提前终止的轨迹数失败后的剩余时间仍按冻结吸收状态计入分母，不能删失败抬高成绩
血糖MSE/RMSE ↓预测血糖与事实观测的偏差预测器/患者模型的准确性；不是改变动作后控制效果的证明
动作MSE、critic TD loss模仿误差与价值拟合误差训练诊断，不作为策略疗效主排名

主表取独立模拟器真实BG；策略只能看到带传感噪声的CGM历史。TIR不是对预测结果算的准确率。每条轨迹3天，排除共同6小时预热后固定792个5分钟点。每方法6封存患者×3餐食/噪声情景×3bolus系数=54条；先平均每位患者的9情景，再对患者等权平均。±为6患者之间SD，而非训练seed SD。

3. 实际前向结构

最近6小时观测：72个5分钟时间点 × 22个特征
  │ 标准化仅由train计算；缺失保留mask与记录年龄
  ▼
展平为1584维 ───────────────┐
                            ├→ 拼接1585维 → MLP actor → 标量z
最初可见6小时基础输注平均值 ┘                3×256 ReLU
  固定参考b，归一化为b/10−1                         │
  每个患者/情景独立；后续不滚动重算                  ▼
                          调整量 Δa = 0.4·tanh(2z/0.4)
                                                   │
                          a = clip(b + Δa, 0, 20) U/h
                                                   │
                          接下来5分钟基础率，非单次注射剂量

仅训练时：1585维状态 + 1维动作 → Q1、Q2
         各自3×256 ReLU + LayerNorm → 长期价值标量
         另有actor/Q目标网络用于稳定TD学习

22维分别是：CGM、过去5分钟基础输注量、bolus记录量、碳水记录量、运动事件数，共5个数值；5个观测mask；5个记录年龄；5个年龄是否已知mask；2个时间编码。运动没有记录不等于确实未运动。所有225名训练患者、1,653,421可用起点保留。

actor不是Transformer或RNN，而是直接处理展平历史的MLP；没有最终接入的患者动力学模型、未来血糖预测头或beam search。actor约53.8万参数，推理只需actor。输出头以零残差初始化。数字0.4是开发集选择的结构超参数，不是医学安全界限；范围外的历史动作目标没有被裁掉。critic目标动作另加ReBRAC目标噪声，因此不能把actor输出范围描述为所有训练Q查询都受同一范围约束。

4. 与参考方法有什么不同

维度RL-DITR参考论文当前O07
任务住院T2D胰岛素注射方案，论文临床数据公开Loop历史离线训练；成人T1D模拟器5分钟基础输注，任务/人群/动作均不同
环境模型学习患者表示、动作条件转移与状态预测最终策略没有使用学得的患者模型；直接使用历史转移做离线Q学习
策略学习患者模型中的rollout，与监督目标联合学习ReBRAC双Q + 行为正则；固定历史参考 + 有界残差actor
决策过程论文的模型式多步规划actor每5分钟给出一个动作；闭环更新观测，没有显式未来搜索
证据原论文的回顾性及临床研究本任务的公开独立仿真，不能继承原论文临床结论

相对ReBRAC，改动集中在策略参数化：把单纯历史→绝对动作改为“历史+固定参考→有界调整”；使用原始全量目标、双Q、行为正则和TD更新。不是提出了新的RL损失或新的risk理论。相对RL-DITR变化大是因为换了算法路线；“换路线”不能自动当作论文创新。

5. 损失、reward与risk的实际定义

以下动作u均是归一化动作a/10−1。V表示合法TD转移，全部起点仍可用于模仿项；未知后续动作/缺口不伪造终止或补零来训练TD。

Actor：Lπ = 100·E_all[(π(s) − u_data)²] − λ·E_V[min(Q1,Q2)(s,π(s))]
λ = stop_gradient(1 / max(E_V|Q_min|, 10⁻⁶))

下一目标动作：u′ = clip(π_target(s′) + clipped_noise, −1, 1)
TD目标：y = r + γ[min Q_target(s′,u′) − 1·(u′ − u′_data)²]
Critic：LQ = E_V[(Q1(s,u_data)−y)² + (Q2(s,u_data)−y)²]

γ = 0.9^(1/12) = 0.991258389
actor_lr = 1e−4；critic_lr = 3e−4；batch = 256；τ = 0.005
目标噪声σ = 0.02，截断±0.05（归一化单位）
训练迭代50,000；critic更新50,000；actor每2次更新，累计25,000。

Actor损失含动作MSE，但其第二项追求长期价值；BC只有第一种模仿目标。最终O07和主表ReBRAC采用相同βπ=100、βQ=1，并没有为O07另造一套新损失。先前尝试过图患者模型的排序CE、方向hinge以及模型辅助actor项，但对应策略结果不佳，最终O07未保留它们。

令BG为mg/dL：
risk(BG) = 10 · [1.509 · ((ln BG)^1.084 − 5.381)]²

status(BG) = −1                                  当BG < 70
             1 − clip(risk(BG),0,15.5)/7.75       其他情况
r_t = status(BG_(t+1)) / 12

risk/status沿用此前按固定作者代码核对后的RL-DITR奖励定义；除以12及γ的换算适配5分钟步长。本轮最终模型没有修改这个risk形状或低血糖惩罚，所有RL比较组共用同一奖励。不能把继承的risk函数列为我方创新。开发与评价使用共同定义，但评价BG来自独立模拟器，训练reward来自日志下一CGM，不共享一个学得的环境模型。

6. 是否incremental、是否SOTA、是否已经做完

当前应判为incremental。残差RL、参考控制和有界输出都有已有研究基础；将其组合进ReBRAC并调出有效范围，是有价值的任务适配，但没有建立新的普遍方法贡献或理论。O07比同结构去RL的封存TIR高21.78pp支持“该配置中RL价值目标有收益”，不能单独证明组合方法的新颖性。

没有证明SOTA。封存TIR我方94.97%、ReBRAC69.96%、FQL55.08%；我方TBR70 2.05%高于ReBRAC0.96%。优势集中在本任务的控制效果，并非所有指标均最好，也不是对整个领域的充分比较。adult009的TBR70/TBR54为9.20%/3.13%，总体门槛通过不是逐患者安全通过。

已经完成的是这份真实离线RL权重、所选baseline/消融、冻结仿真研究评价与推理交付。尚未完成非incremental方法创新、真实预测器接入、Core真实双模型产品闭环及临床验证。

7. ICML预测模型怎样接、效果差怎样退

要先取得代码、权重、网络配置、归一化、输入输出时间窗、单位、论文说明及训练患者/数据划分。核对它是历史条件的未来CGM预测器，还是具有可信动作响应的患者动力学模型；不能因为它来自ICML，就假定能预测未执行剂量的后果。

接法影响必要验证
第一步：作为独立预测服务F，与冻结O07并行预测器输出和RL输出分别作为Core证据。O07没有预测输入通道，同一历史的原始RL动作应保持一致。窗口、归一化、患者训练重叠、预测误差、域适配；模型/输入/父预测绑定与失败路径；单测不足以替代真实联调。
把F预测/表示作为RL新输入改变策略输入和分布，需要训练或有验证的适配；不能直接拼接到现有1585维模型。冻结开发协议、重训候选、相同场景成对闭环比较，检查低血糖/失败/覆盖率。
用F作为RL训练环境或动作筛选器要求F具备动作条件、反事实响应与长展开能力；普通预测器没有自动满足这些要求。同状态动作干预响应和独立生理评价；不能只凭较小MSE接入并宣称更好。

保留V0＝现有O07权重/归一化/输入合同/评价器。新增预测器作为独立版本，先shadow/离线运行，不覆盖V0。接入后分开评价：预测误差、原始RL动作一致性、拒收/覆盖率、实际执行闭环TIR/TBR。若只做旁路预测，原始O07动作变化属于需调查的集成差异；若预测参与闸门，实际执行结果与覆盖率可能变化，需要单独测。

候选变差则不晋升，撤回新增数值输入/控制逻辑，保留原始研究配置及失败证据。现有状态只有研究RL，没有已验收的完整双模型产品，所以“退回”是回到研究基线，不是允许绕过预测模型继续发布给药。没有有效预测或合格RL时，Core仍需拒绝个体化给药发布，不能以零剂量或“维持”冒充模型结果。

本次T01已被查看，以后可用于回归测试，但不能拿同一批结果反复调参后再称盲测。新候选须先冻结新评价协议；新场景只证明新场景泛化，若要未见患者证据还需独立患者/公开资源，不能混称。
