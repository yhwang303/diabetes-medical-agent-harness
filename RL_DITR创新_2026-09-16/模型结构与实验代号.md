## 2. 输入与患者模型

每次输入最近72个5分钟记录，即6小时。每时点包含22维：

- 5项生理/行为数值：CGM、上一间隔基础量、bolus、已记录碳水、运动事件数。
- 对这5项分别记录是否观测、距上次记录的时间、历史是否曾有记录，共15维。
- 2项相对时间信息。

缺失餐食/运动继续进入训练，通过数值和缺失特征区分，不删掉对应患者或起点。真实BG、未来餐食、模拟器隐藏状态不作为策略输入。

共同结构：fR为3层因果Transformer encoder，hidden256、8heads、FF2048；fT为3层Transformer decoder，cross-attend观测历史；GLU/WTR/reward/value各有MLP头。MLP使用3个Linear，按论文文字实现；作者代码对应MLP是2个Linear，这个差异已公开。

R03与H01患者模型参数均为9,621,295，策略为132,098。容量相同，改变的是fT的依赖关系：

```text
R03：z[k+1] = fT(z[k], action_prefix[0:k], observed_history)
H01：z[k+1] = fT(z[0], action_prefix[0:k], observed_history)
```

H01训练时可并行计算所有因果prefix；未来动作不能影响更早预测。策略仍根据预测出来的当前latent决定下一动作，所以模型内策略rollout仍逐步进行。reward头仍读取当前预测latent和当前动作；不是删掉所有状态依赖。

## 3. 策略与规划

π是三Linear的MLP，输出[0,20] U/h截尾高斯的均值与尺度；边界使用概率质量，内部使用连续密度。这个范围是既有研究动作合同，不是个体化医学安全界。

训练患者模型时更新fR/fT/预测和reward/value头；训练策略时冻结患者模型，π通过历史回报项、模型想象回报项和动作监督项更新。

推理有两种：

1. **仅策略**：输出高斯均值；这是经过RL训练的π，并非BC。
2. **策略+规划**：每层10个策略分位点候选，beam10、12个5分钟步；累计预测reward加末端V，执行首个动作，再观察重规划。

新增、单独评价的推理消融是**4小时动作块beam**：48个5分钟点，分成3个16步动作块；每块由当前π提出10个候选，保留beam10。评分仍累加全部48个reward并加尾值，不只看终点；实际仍只执行第一个5分钟动作。R04/H02/H03分别使用完全相同的该规划规则，另保留原1小时逐步beam结果。

块长度设为1时，已在两个实际权重上验证与原beam的首动作和分数相符；患者之间隔离。工程测试使用旧60分钟训练权重，仅证明实现正确，不能证明4小时控制有效。动作块规划具有已有方法依据，不单独算创新。新增仿真训练计划目前是常值基础率，变化动作块仍存在覆盖不足风险，须以独立闭环结果检验。

## 4. 损失和reward改了什么

```text
L_patient = MSE(CGM) + CE(WTR) + 0.1 MSE(latent consistency)
            + two-hot CE(reward) + two-hot CE(value)
L_policy = -E[R_logged log π(a_logged|z)]
           -E[R_imagined log π(a_sampled|z)]
           + MSE(policy_mean, a_logged)
```

R03/H01的reward/value分类支持为3/41 bins，并按作者源码对bins取mean。R01/R02的标量MSE尝试单独保留，不能混成同一实验。

H01没有改变reward形状或损失，只改变fT计算依赖。H03新增：

```text
L_pair = mean_valid[(ΔCGM_pred-ΔCGM_sim)^2]
         + mean_valid[(Δstatus_pred-Δstatus_sim)^2]
L_mixed = L_Loop + L_sim_fact + 1·L_pair
```

Δ针对同一初始状态、相同餐食/bolus/随机流下的两条不同基础率分支。配对项不强制“加胰岛素必须降多少糖”，而由仿真实际结果监督。事实对照也获得全部相同分支。采用已有配对思想不自动构成原创贡献。

5分钟reward是原作者式status除以12，折扣γ=0.9^(1/12)。当前所有这些版本均未为了成绩改变status/risk形状。真实仿真终止的bootstrap为0；记录缺失不被当作终止。

## 5. step、epoch与选择

一个step是一次优化器更新；一个epoch是全部1,653,421个Loop起点访问一遍。本轮batch上限256，按患者组织末批，因此一遍是6580步，不是精确的样本数除以256。患者阶段和策略阶段分别计步。

患者检查点按固定验证集RMSE30+RMSE60选择；策略不能按动作MSE决定是否好用，还需比较相同独立仿真情景的TIR、TBR、提前终止、低糖事件和剂量变化。早期6000步是一个权重检查点的训练位置，不是6000个epoch，也不是完成医学验证。

## 6. 创新与接入判断

动作prefix已存在ADM-v2/MAC近邻，配对动作效应也有CQM等先例。当前分别验证结构和目标是否有效，尚不能宣称非incremental创新，更不能宣称SOTA。

ICML预测器尚未提供或接入。后续应冻结本轮可复现权重/数据/协议，再独立接入和比较；预测器可能改变信息分布和误差，不能因其预测MSE优秀就默认给药控制改善。若联合系统退化，应保留并恢复经验证的旧研究版本，调查接口/单位/时间对齐和模型耦合；不能把未通过的研究版本发布给患者。Core准入与真实患者验证是另外的步骤。

接入有两个不同层次，不能混在一次对比里：

- **先作为独立预测工具接入**：锁定预测模型版本、输入/输出时间点、单位和适用范围，保持RL输入合同不变，先评估两模型并行工作的系统。一个不接受候选剂量的预测器，不能直接当成不同剂量的反事实评价器。
- **再研究耦合**：若把ICML预测当作RL输入，或替换RL患者模型的一部分，需要重新训练/校准对应模块，并做“旧RL”“新预测+旧RL”“重训后的耦合模型”分组。必须检查患者划分、预处理和训练资料重叠，避免把真实未来值或同患者测试资料漏进训练。

所谓回退，是研究部署版本及接口配置切回保留的版本；不会覆盖旧权重、伪造旧测试集封存状态，也不能撤销已经发生的物理给药。本轮没有开展真实患者给药。

## 9. H04：参考轨迹与干预响应分解（2026-09-16）

H04仍以完整H02的RL-DITR编码器、参考转移、预测头、价值头和策略为骨干。改变的是动作如何作用于未来血糖和潜在状态：

```text
6小时观测历史 h → 冻结 fR → z0、历史memory
从历史取最后一次实际基础率 a_ref（U/h）
fT/fP(h, 重复a_ref的计划) → G_ref[1:48]、z_ref[1:48]
候选计划 a[1:48] → Δa = a − a_ref
z0 → 条件响应系数（8个Bernstein基函数）
ΔG[t] = Σ(s≤t) k_G(z0,t−s)·Δa[s]
Δz[t] = Σ(s≤t) k_z(z0,t−s)·Δa[s]，潜在响应rank16
G[t] = G_ref[t] + ΔG[t]
z[t] = z_ref[t] + Δz[t] → π和V
r[t] = 原status(G[t])/12 → 规划/想象回报
```

参考基础率来自可用观测，不能读取仿真器标称基础率。全历史缺失时零仅作响应坐标原点，不是发布零剂量建议。每5分钟仍以新观测重新估计历史、响应核与动作。

**新增训练**：P01对同一状态不同动作的血糖差做MSE；P03对观测窗口编码得到的潜在状态差做MSE，监督步为1/6/12/24/48。两者均固定100epoch、3200更新，不按开发结果选检查点；H02背景被冻结，保留全部Loop预训练。原504组恒定干预反复使用，不是新增患者。P02为8参数共享响应核消融。

**策略目标**：H04使用R05后的有界回报NLL目标；先继承H02最终策略，再完整访问全部1,653,421起点一次。R07也继承同一策略、相同额外epoch和seed，患者模型保持H02。R07只控制额外策略优化，新增响应训练及参数量需另外报告。

**与H03的实质区别**：H03只在原prefix输出上增加配对loss；H04把背景预测与动作响应分开，显式约束时间因果性，并将干预后的latent传到π/V。背景观测相关性不会直接成为新增响应模块的训练标签。

**边界**：这并不自动构成顶会原创。局部线性与时间不变是假设；不保证非线性大剂量或远期外推。P02也解决探针方向，说明不能把收益全部说成个体化。reward函数形状不变，但由独立reward头改为点预测血糖的status；它不等于不确定性下的期望风险。保留的价值/WTR头对新latent也需要独立验证。H04尚待完整控制实验。
