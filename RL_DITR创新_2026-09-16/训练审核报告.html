结构与梯度

72×22历史（数值、缺失标记、记录年龄、时间）
  → fR：3层Transformer / hidden256 / 8heads
  → 初始患者latent z0 + 历史memory
候选基础率a（U/h）+ 时间 + 当前latent
  → fT：3层Transformer decoder，cross-attend历史
  → 下一个latent → fP：血糖 / WTR概率
  → reward头，value头
π：3层MLP → 连续有界高斯的均值/尺度
  → 真实历史回报项 + 模型生成回报项 + 行为监督
  → B10、K12 beam：累计折扣reward + 末端V
  → 每5分钟执行首个基础率动作，再观察重规划

患者训练时更新fR/fT/fP/reward/V；策略训练时冻结患者模型，只有π接收梯度。R02的status范围为[-1,1]，每5分钟reward=status/12；γ=0.9^(1/12)，价值范围按几何级数界限制。奖励形状未为追求成绩修改。
