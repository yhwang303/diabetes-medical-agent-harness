# RL-DITR 基底与创新：评价文献核查及冻结协议建议

核查日期：2026-09-16。本文是研究协议建议，不是已完成实验或临床有效性结论。本文最初形成于文献核查阶段，当时未运行新训练。此后实际AutoDL训练与开发仿真已开展，当前完成情况以训练审核报告、检查点和根目录工作记录为准；本文的最终冻结建议不等于已经执行。

## 1. 结论与执行边界

**主问题应是“动作改变以后，独立环境里的控制是否改善”，不能用血糖 MSE 或自己学出的世界模型奖励回答。** 建议保留四层证据：真实记录拟合 → 共同候选动作的反事实检验 → 长展开误差 → 独立闭环效果。主效果量是标准 TIR 的配对差，同时强制呈现低血糖与失败；它不是单独的通行证。

- 每个待训练方法只用 **1 个训练 seed**。仿真情景随机重复不等于训练重复。
- FQL/ReBRAC 本轮 **不重新训练、不执行新仿真**；仅对已存原始轨迹离线补算指标。
- adult001–010、既有 D/T 与 T01 均已经曝光。新实验只能增加“已知虚拟患者、新冻结情景”的证据，不能声称未见患者泛化。
- Loop 保留全部 225 个训练患者与 1,653,421 个训练起点；food/exercise 是带缺失 mask 的稀疏输入，不能按是否有记录删人、删训练起点。评价子组是分层报告，不是训练过滤。
- 不依赖私有医院数据，不改公开患者机理参数迎合方法，不借旧 FQL/ReBRAC 分数填充新场景比较。
- “按方法复现”与“原论文临床结果复现”不同：RL-DITR 原任务为住院 T2D 胰岛素治疗；本项目是公开数据支持的成人 T1D 基础泵速率研究。须保留逐模块对应表并标明任务适配。

## 3. 四层评价：最小而有解释力

### A. 真实轨迹拟合及概率校准

1. 在当前真实数据患者划分上报告 15/30/60/120/240 min 的 MAE 与 RMSE（mg/dL），模型不支持的时长明确写 N/A；不能将只训练了短时目标的模型硬接成长时优势。模型在同一预测起点自由展开，不能中途喂入真实未来 BG 后称作多步预测。
2. 模型若必须条件化未来真实动作，这属于 **已记录动作条件下的动力学预测**，单列；不能把实际未来餐食/运动与剂量泄漏给部署策略。另列部署时真实可用信息的预测误差。
3. 每患者先汇总，再跨患者宏平均；附样本加权结果和有效起点数。按真实未来低糖/范围内/高糖及 food/exercise 是否有记录分层，显示患者数、事件数和有效观测数。稀疏“未记录”不等于“没有吃饭/没有运动”。
4. 有概率输出时，报告 80%/95% 预测区间的实际覆盖与平均宽度，并画名义覆盖—实际覆盖图；需要概率分布才计算 NLL。只有点输出就记校准 N/A。WTR/低糖概率头用 Brier score 与可靠性图，不能仅用 AUROC 称已校准。任何温度/方差校准仅在验证集拟合。

对患者 p、时长 h 的有效集合 I：

`MAE(p,h)=mean_i |g_hat(i,h)-g(i,h)|`

`RMSE(p,h)=sqrt(mean_i (g_hat(i,h)-g(i,h))²)`

`PICP(q)=mean_i 1[L_q(i)≤g(i)≤U_q(i)]`；`Width(q)=mean_i[U_q(i)-L_q(i)]`

`Brier=mean_i (Pr(event_i)-1[event_i])²`

上述 h 网格、宏平均、覆盖/宽度和分层是本项目建议，不是宣称每篇论文都使用。单模型内部的随机采样不等于多个训练 seed；网络间分歧也不自动等于统计置信区间。

### B. 反事实动作效应：使用共同状态/候选集

冻结同一批模拟历史状态、同一组可执行动作序列、同一未来外生餐食/传感器随机流。所有模型评价完全相同的候选，不能各自挑选容易预测的轨迹。动作不能超出合同，记录 requested 与实际 pump delivered。

对状态 s、参考动作 a0 与候选 a：

`effect_true(s,a,h)=G_sim(s,a,h)-G_sim(s,a0,h)`

`effect_pred(s,a,h)=G_model(s,a,h)-G_model(s,a0,h)`

报告 `effect_MAE(h)=mean |effect_pred-effect_true|`（30/60/120/240 min）；另报告候选排序一致性及由错误选择带来的 **模拟器真实结局差**。例如先冻结效用 J，再用 `regret=J_sim(a_best_in_pool)-J_sim(a_chosen_by_model)`；明确只是有限候选池内遗憾，不是全局最优差距。J 的风险权重属于预先规定的诊断工具，不能替代原始 TIR/TBR 指标。

近似无效应的动作对可用预先冻结的数值容差标记“无差别”，但同时报告数量和完整效应误差；不能挑选方向阈值把训练先验变成通过条件。真实 Loop 的观察记录没有配对反事实真值；对模拟器检验通过只能称“符合该独立模拟机制”。策略不得看到未来外生序列，评价器可以用于构造受控真值。

### C. 長展开一致性

与 B 共用候选轨迹，在 15–240 min 逐时长画 MAE/RMSE、效应误差与失效比例；不以平均值掩盖长时偏移。不同预测 horizon 对应共同有效起点，同时附最大可用样本结果，避免模型因删去困难长序列显得更好。候选动作的扰动结果是机制诊断；最终效果仍由闭环证据决定。

### D. 独立闭环：主结果与必要解释

| 层级 | 指标 | 回答的问题 |
|---|---|---|
| 主效果量 | 标准 TIR 70–180 的患者宏平均与配对差（百分点） | 正常范围时间是否增加？ |
| 必须并列 | TBR<54、TBR<70；仿真失败/提前终止率及原因；每患者结果 | 增益是否伴随低糖或控制崩溃？ |
| 解释机制 | TAR>180、TAR>250；CV；LBGI/HBGI | 是减少高糖，还是更剧烈摆动？ |
| 尾部风险 | ≥15 min 低糖事件/患者日、最长持续、<54 持续≥120 min事件；最差患者 | 平均占比是否掩盖集中伤害？ |
| 控制成本 | 实际基础/餐时 U/day 分列、动作总变差/日、泵裁剪/量化比例、推理时间 | 是否靠不合理剂量、剧烈变化或额外资源换效果？ |

不把十多个指标任意加权为一个“总分”。HBGI/LBGI 与 TBR/TAR 有重叠，前者用来说明离目标多远；不是额外十次显著性获胜机会。临床不可观测的 ketoacidosis、需协助严重低糖不得臆造为已有事件。

## 4. 可直接实现的指标口径

所有阈值以 mg/dL 为单位。对 warmup 后有效区间权重 `w_t`（分钟）：

`TimePct(A)=100 × Σ w_t·1[g_t∈A] / Σ w_t`

TIR 用 `70≤g≤180`；TBR70 用 `g<70`，TBR54 用 `g<54`（后者包含于前者）；TAR180 用 `g>180`，TAR250 用 `g>250`（后者包含于前者）。另画五个互斥区间时用 `<54`、`54≤g<70`、`70≤g≤180`、`180<g≤250`、`>250`，不能把嵌套区间相加。

`μ=Σw_t g_t/Σw_t`；`SD=sqrt(Σw_t(g_t-μ)²/Σw_t)`；`CV=100·SD/μ`。这是时长加权总体 SD（ddof=0），报告实现版本，避免与样本 SD 混用。

风险使用项目已固定 simglucose commit `a6f6777586c860457a2a1e6cce6d0bd3fd33d1cc` 的 [risk.py](https://github.com/jxx123/simglucose/blob/a6f6777586c860457a2a1e6cce6d0bd3fd33d1cc/simglucose/analysis/risk.py)：

- `f(g)=1.509·[(ln g)^1.084−5.381]`，`r=10·f²`；负分支为低糖风险、正分支为高糖风险，分别对 **全部**有效时长取均值，不能仅对低糖/高糖子集平均。
- 此 commit 在 `g≤20` 返回 `(L,H)=(100,0)`，`g≥600` 返回 `(0,100)`；其余用上式。报告名为“simglucose 截断 Kovatchev 风险”，不与论文中的 Magni risk 混称，也不静默删非正/非有限值。
- 非有限值是失败，需要另记，不能伪造有限风险。

低糖事件按 2017 共识：阈值下连续至少 15 min 起算；≥70 连续15 min 才结束；另报 <54 连续≥120 min。实现需要冻结离散时间约定：每个 5 min 记录代表一个 5 min 区间，3 个连续低区间是15 min，不能把“3个瞬时样本相距10 min”混为15 min。事件起点回溯至第一次低区间；计数按恢复确认分割，报告实际阈值下累计分钟与事件跨度，末尾未恢复标记右删失。不要把终止后的虚构值延长成真实事件。

`basal_U=Σ delivered_basal_U_per_hour(t)·w_t/60`；餐时总量单独 `Σ bolus_U`。完整结局 `U/day=total_U/(planned_minutes/1440)`。提前终止时同时报实际累计 U、观测小时及按观测时长计算的率；不能把不足一天的总量直接冠名全天剂量。

`TV_per_day=Σ |delivered_basal(t)-delivered_basal(t-1)| / observed_days`，单位 `(U/h)/day`。这是控制平滑度，不是生理安全证明。requested 与 delivered 都保存；量化/限幅非零不意味着错误，但必须对所有方法一致处理。

主分析建议取模拟器真实 BG（独立环境结局），同时附传感器 CGM 的同一组指标作为可观测结果。临床 CGM 参考目标只对 CGM 表作参照；不混合 BG 与 CGM，策略只能读合同规定观测。

## 5. 两个比较面板，不能混在一张排名中

### 面板 A：T01 已曝光回归

复用旧 FQL/ReBRAC、固定参考等 **现存**轨迹，只离线补算。若新方法在同一个已曝光合同下运行，称开发回归比较，不能称封存证据。需同患者、同情景 seed、同 bolus factor、同传感器/泵、同预热/时长才可配对。

已核对文件例：`RL进阶对比_2026-09-15/results/T01_frozen_sealed_comparison/FQL_alpha100_p7_s73103_b0.8.json`。原始 `records` 含 minute、BG/CGM、requested/delivered basal、bolus、meal、warmup；该失败例预热后仅有376步，而旧固定分母792步，缺416步。旧代码用终止后惩罚血糖填充其余时长。

因此：

- 保留历史“带失败惩罚 TIR”等原指标和其名字，不能悄悄更换导致历史排名失真。
- 新补 CV、风险、事件、实际胰岛素使用 **真实存下的记录**，并列 coverage 与失败。600/10 的惩罚填值不是观测。
- observed-only TIR/CV 可能因早停选择性变好，不作为总排名单一依据；失败例不删除。模型输出前后记录对齐和 warmup 约定须核查。

### 面板 B：新冻结情景

只比较完整 RL-DITR 基底、我方创新、必要消融、预先固定参考。FQL/ReBRAC 标 N/A（用户本轮不重跑），不跨情景搬分数，也不宣称在新情景击败二者。

新冻结必须同时覆盖：情景生成合同、外生 seed 清单、方法 checkpoint SHA、代码/依赖/模拟器 commit、动作限幅/量化、全部指标公式、失败处理。先完成开发 pilot，再冻结主模型与协议，之后一次性评价。新结果一旦用于调参，就自动转为开发证据；新的封存证据须另起版本，不能换名称维持“未曝光”。

## 6. 建议的一次性冻结设计（尚未执行）

建议由主任务根据计算预算在运行前确定最终合同，下面是可执行起点而非已冻结事实：

1. **公共环境不变**：adult001–010，5 min 控制，现有 GuardianRT/Insulet，公开机理参数不变；预热规则与初始状态统一。明确 `7 days` 是否包含预热，建议记成“6 h 预热 + 7×24 h 评价”。长于旧3日有助发现剂量累积问题，不宣称已满足临床14日数据要求。
2. **主情景**：同任务、正常餐食变化的新随机 realization；每成人至少3个新情景 seed，先冻结所有具体餐食序列/传感器种子。搜索全部旧 manifest/结果防止重用，不只避开3101/73101等已知编号。种子名称换了但序列相同不算新。
3. **独立压力情景**：预先选择两类，例如餐时/餐量更不规则、餐时 bolus 欠量/过量。参数取值须在看新结果前写明；不要从跑出的失败个案挑一个对我方最有利的扰动。主情景作主比较，压力情景作完整分项，不把更多容易情景稀释困难情景。
4. **未来信息**：全方法统一“只看到历史 + 当前已发生/已宣布信息”。若采用共同餐时 bolus，当前餐量可用于该参考模块，但未来餐量/时间不能输入 RL。未知餐食与餐时已宣布是两个合同，不能某方法提前吃到信息。完全无 bolus 是新的控制任务，不能悄悄拿来当原 basal 合同。
5. **运动边界**：公开 simglucose 不会因输入 exercise 特征自动产生正确运动生理。保留 Loop 稀疏特征与分层误差，但不编造仿真运动控制有效性；独立运动机制证据暂缺。
6. **消融**：仅保留能隔离创新因素的最少消融，训练预算/数据/动作/搜索次数一致。可共享合规的预训练基底，但明确由此产生的依赖；仍不能把同一个 checkpoint 多次推理算多个训练 seed。
7. **失败口径先定**：记录原生环境 done、非有限、worker/超时/协议失败及首次时间。不要借用 AAAI 的70/200终止改变当前环境，也不要为好看让失败回合消失。尽可能在统一安全处理下完整仿真；若环境不可继续，保留失败及观测比例，另给 TIR 的缺失结局界：下界=已知在范围分钟/计划分钟，上界=(已知在范围分钟+缺失分钟)/计划分钟。它是界，不是猜测真实血糖。

固定 nominal+bolus 参考使用公开静态参数，可能比学习策略拥有额外先验；应明示这类“有特权参考”的角色。若已有公开控制器能在相同可用信息下公平运行，可另作固定参考，但不在结果出来后挑最弱者。

## 7. 统计单位、主要声明与验收结论

每方法、患者、情景生成一个 episode 摘要；先在患者内平均同类重复，再跨10患者等权汇总。主比较为同患者同随机外生条件下的配对差：

`d_p=mean_s[TIR_innovation(p,s)−TIR_RLDITR(p,s)]`

`ΔTIR=mean_p d_p`

同法给 ΔTBR54、ΔTBR70、Δ失败率，以及10名患者原始差值图。新情景数、天数、5 min 窗口不能冒充独立患者数。可做成对分层 bootstrap：按患者成簇重采样，并在簇内成对抽情景；固定随机 seed，报告95%区间与方法。样本只有10，区间近似且敏感，不能把统计显著性包装为现实人群代表性。另可报告固定10患者条件下的情景不确定性，但标题必须写清其条件。

**只有一个训练 seed，所有区间都不包含训练随机性的波动。** 不报告跨训练 seed 的 SD，不写算法稳定性已经成立。既有旧模型也只有其保存实例的比较。

建议以预先唯一的“创新 vs RL-DITR 基底”作主比较，其余消融是解释性分析。避免每个指标/情景都检验后挑出 p<0.05 的结果。不能因为安全差异“不显著”就宣布安全非劣；非劣界值需要事先有医学或应用依据，本次不能凭经验杜撰。

建议最终研究结论采用三档，**不改医生标准制造二元通过**：

- **支持继续作为 Harness 研究候选**：实现对应清晰；独立模拟中主效果改善，低糖与失败无观察到的恶化，跨患者/压力情景结果一致，且反事实/长展开未暴露明显失真。若置信区间尚不能排除风险增加，应同时写“安全非劣尚未建立”。这仍只是受控研究候选，不允许真实患者给药。
- **存在效用—风险取舍或证据不足**：TIR上升但TBR/失败上升；或均值变好而区间很宽/少数患者显著退化；或只在曝光T01更好。展示取舍及不确定性，不宣布全面胜出。
- **当前不支持作为数值 RL 模块**：动作效应错误、独立闭环失控、非有限/动作语义不一致，或仅自己模型评分上升。明确归因为数据支持不足、模型结构、控制搜索、合同不匹配或尚不能区分，不能凭一个 MSE 猜原因。

“支持作为研究候选”并不自动满足 Harness 发布：模型合同、适用范围、两模型证据、失败弃权与 Core 闸门仍是独立工程要求；反之工程测试通过也不替代本文件中的模型效果证据。没有“达到顶会门槛”这种通用分数线；有价值的论文结论依赖可信设计、充分消融、适当限制与可复现证据。
