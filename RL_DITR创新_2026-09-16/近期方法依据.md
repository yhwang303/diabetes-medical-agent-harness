# RL-DITR 基底上的近期方法依据与可检验假说

日期：2026-09-16。任务边界：先跑通 RL-DITR 的患者模型→策略训练→模型式规划完整链，再讨论创新。新训练仅 seed=260915；不重训 FQL/ReBRAC；本调研不动训练代码或 AutoDL。

## 结论先行

建议第一条可训练路线是 **“动作序列直接驱动、保留全程风险的患者模型”**：保留 RL-DITR 的 fR/fT/fP、历史/想象/监督三项策略损失和 beam 规划，实质改变 fT 的长时误差传播路径，而不是把主体换成 ReBRAC、加输出限幅或强塞单调惩罚。

依据最贴近的是 **ADM-v2（ICLR 2026）＋MAC（ICLR 2026）**；TD-MPC2（ICLR 2024）解释为何表示学习应对决策负责；BECAUSE（NeurIPS 2024）提醒预测拟合与动作有效性并不等同。**这些论文已经覆盖直接多步模型、动作块、价值相关表示、悲观规划等大量基础思想。单纯把它们接到 RL-DITR，不能诚实地宣称新算法或非增量论文贡献。** 下文给出两个可证伪研究假说及超出直接移植的候选方向，创新结论要等机制实验。

## 1. 回到 RL-DITR 原始链路

本轮已重读本地论文 `Loop数据集/训练管线_v1/文献/RL-DITR_全文.txt` 约1330–1470行及固定作者源码 `RL训练_2026-09-15/vendor/RL-DITR/ts/models/patient_model.py`、`agent.py`。固定作者 commit `5080fdbe43979f9b8a9616fbc120aae4ac25842a`。既有审计见 `RL训练_2026-09-15/method_audit.md`，本轮没有把审计摘要当作唯一证据。

原方法必须保留的对应关系：

```text
h_t = fR(O_≤t)
hat_h_(t+1), hat_r_t = fT(h_t,a_t)
hat_glucose, hat_WTR = fP(h_t)

L_patient = L_GLU + L_WTR + μ L_consistency
L_policy = −E[R_logged logπ(a_logged|h_logged)]
           −ε1 E[R_imagined logπ(a_sampled|h_imagined)]
           +ε2 L_supervised_logged

score(A_0:K−1) = Σ_(k=0..K−1) γ^k rhat_k + γ^K V(hhat_K)
```

原作者 fT 每轮把预测latent `state_t_next` 重新作为下轮输入，并cross-attend初始历史；本地2026-09-15患者模型也把上一步预测latent `z` 放入下轮decoder query。因此“动作序列驱动的直接预测”确实会改变计算依赖图，不只是给现有残差模型换名字。

连续基础率U/h与5分钟时间网格是本任务适配；不能复用论文的1–40单次剂量动作意义。历史回报项不是无偏on-policy梯度；想象回报是学习模型中的回报。奖励logits必须逐步解码后再累加。原代码存在loss mask、默认RL权重0、beam尾值折扣等问题，修复应写作基底复现修正，不能计作研究创新。

### 2.1 已核对的关键公式与容易误写的地方

**ADM-v2代码真实依赖图**（紧凑改写，非逐字复制）：

```text
h_j^0 = Encoder(observed_state_j)
h_j^(i+1) = GRU(action_(j+i), h_j^i)
(μ_Δs, μ_r, logσ²) = Head(h_j^(k−1), h_j^k)
L_NLL = mean[(target−μ)² exp(−logσ²) + logσ²]
```

其中源代码训练 `target_Δs = s_(j+k)−s_(j+k−1)`，而不是 `s_(j+k)−s_j`！模型的RNN隐状态只由动作推进，输出的是末一步状态差与reward；部署仍需把Δs加到当前状态，不能称完全消除所有数值积分误差。它从多个过去观测锚点初始化隐状态并并行预测，代码不确定性为 `sqrt(mean_dimensions Var_anchor(next_state_mean))`。该量是模型预测分歧，不是已经校准的真实患者置信区间。

**MAC作者实现**：动作chunk `A=(a_t,…,a_(t+c−1))`，`T(h,A)`直接预测chunk末状态，`R(h,A)`拟合chunk奖励；均为平方损失。行为chunk流匹配：

```text
x_τ=(1−τ)z+τ A_data, z~N(0,I)
L_flow = E||vθ(h,x_τ,τ)−(A_data−z)||²
```

作者还蒸馏成单步生成器以加速。每次采N个行为候选并以Q argmax选优；代码并不是需要已归一化接受率的经典accept/reject。默认chunk10、rollout10、候选train8/test32、测试只执行chunk首个动作；chunk折扣为 `γ^c`，不是γ。想象价值目标用GAE，默认λ=1。MAC的success/termination头基于任务终止标签；**不能把CGM缺失mask照搬成成功或生理终止**。

**TD-MPC2（示意，分布投影细节见MIT源）**：

```text
L = Σ_k ρ^k [ c_z ||z_hat_(k+1)−sg(fR(o_(k+1)))||²
                 + c_r CE(reward_logits, two_hot(r_k))
                 + c_Q Σ_i CE(Q_logits_i, two_hot(r_k+γ Q_target(next_z,π(next_z)))) ]
```

这为决策相关表示提供依据，但它本来就是任务导向latent学习，不能把“加return头”作为新贡献。

**BECAUSE原式与适用假设**：论文式(3)为 `T(s'|s,a,u_c)=φ(s,a)^T M(u_c) μ(s')`；式(5)在预测误差外稀疏化M；式(7)按行为概率对M加权；式(8)训练能量模型，再作保守规划。论文假设潜在混杂分布时间不变、跨环境因果图不变等。**本任务没有证明这些假设，不得把学习一个M或对行为概率加权视作无条件消除所有未测混杂。**

## 3. 假说 H1：保留细粒度风险路径的直接动作计划患者模型（推荐先做）

### 问题与可证伪主张

在同样的初始72×22历史和相同未来候选动作下，RL-DITR长时误差部分来自预测latent反复进入后续转移。**把动作驱动隐状态与预测患者状态解耦，并监督chunk内部每5分钟的GLU/WTR与reward，能否在保持单步精度的同时减少长时“计划排序错误”，从而改善同一RL-DITR策略/beam的闭环表现？**

这不是“更换Transformer为GRU”的假说；核心自变量是**预测患者latent是否作为下一转移输入**。控制网络容量和计算量后才有解释力。

### 我们拟改动（公式属于提案，非引用原论文）

保持fR。从历史锚点j获得 `z_j=fR(H_j)`，初始化动作记忆 `u_0=P(z_j)`；每次仅输入真实/候选动作与时间：

```text
u_(k+1)=GRU_or_causal_attention(u_k, embed(a_(j+k), Δt))
z_hat_(j+k+1)=D(z_j,u_(k+1),k+1)
(g_hat_k,w_hat_k,r_hat_k)=fP_and_reward(z_hat_k)
```

`z_hat`不反馈进入u递推。实现可以继续采用Transformer动作序列编码和初始历史cross-attention，以避免把架构容量变化混入机制比较。生成过程仍是因果的：策略先依据已生成状态采下一动作，再推进动作记忆；训练时可对已给定完整候选动作序列并行评估所有prefix。

```text
L_H1 = L_original_patient
     + Σ_(k∈valid prefixes) [ λ_g ℓ(g_hat_k,g_k)
                              + λ_w CE(w_hat_k,w_k)
                              + λ_r ℓ(r_hat_k,r_k)
                              + λ_z ||z_hat_k−sg(fR(H_(j+k)))||² ]
```

保留1-step分支与短/长prefix任务；所有起点继续训练可用prefix，不要求都有长轨迹，不因餐食/运动缺失删样本。奖励函数先冻结沿用基线；否则分不清收益来自模型还是改评分。

**比简单移植更值得研究的部分**：常见chunk模型只顾chunk末状态/累计回报。本任务的候选贡献应是“在长期剂量延迟下，规划必须保留chunk内部风险路径”，即同终点血糖/同总reward的两条轨迹也可能有不同早期低值暴露。输出/监督逐5分钟路径，规划时逐步计风险与相同尾值，不用endpoint代替整段。仍需检索/实验，不能预先保证新颖性。

### RL-DITR对应与政策学习

- fR：保留稀疏多模态历史编码。
- fT：改变计算依赖图，仍是受动作控制的患者状态转移。
- fP：保留GLU/WTR，增加长prefix监督而非另造model-free主体。
- π与V：继续三项原始策略目标。不能只用行为chunk选优把LRL1/LRL2删掉。
- 规划：仍比较 `Σγ^kr_k+γ^KV(z_K)` 的beam；候选可混合当前RL策略与行为策略，但两者比例/候选数先冻结。
- 执行：每5分钟只执行计划首动作并重新观测；长chunk不意味着盲执行整段基础率。

### 机制消融（同seed260915）

A0 完整修正的RL-DITR；A1 仅同容量直接动作路径、仍单步GLU损失；A2 A1+逐prefix监督；A3 A2但仅监督/评价chunk末点；A4 A2+逐5分钟reward路径（主提案）。若A2/A4相对A1没有变化，则证据支持“结构变化够用”，不支持宣称path-risk机制有效。若收益只来自更大参数或更长训练，应撤回机制贡献。

指标：同物理时长30/60/120/240分钟rollout误差、累计风险误差、低值时间定位误差、候选计划rank相关/Top1 regret、模型预测收益−独立仿真实得收益、闭环TIR/TBR、规划时间。单纯MSE变小不够。

### 数据识别与限制

直接预测不等于去混杂。未来未记录的餐食/运动及bolus仍可影响长时模型。训练用future action合法，但部署的future exogenous只能使用当时已知计划或明确情景分布，不能喂未来实际记录。观察数据中未覆盖的高/低动作范围仍无可识别性。长时有效prefix可能较少，必须报分层数量；不能为完整长序列砍掉短样本。

## 4. 假说 H2：双世界配对干预校准患者模型的动作对比（后续，有数据前提）

### 问题与可证伪主张

Loop闭环记录可能只足以学到“什么时候控制器加胰岛素”，不能从单一事实轨迹直接得出“同一状态下换剂量会如何”。**使用公开仿真中可重置的相同潜在状态与相同外生扰动，生成不同基础率计划的配对结果，训练患者模型保留候选计划之间的风险差；在未参与训练的虚拟成人/情景上，能否减少计划排序错误和模型利用，而不明显破坏Loop事实预测？**

这是对监督信息来源与模型目标的改变，不是手工指定剂量必须单调下降或加一个经验正则。它只识别仿真器中的干预效应。

### 原始贡献与近邻，不能偷换

BECAUSE表明混杂/策略分布偏移应进入模型表示和规划设计；但不能直接给Loop提供反事实真值。最近 [Counterfactual Quotient Models: Learning What Actions Change, Not What the World Does](https://arxiv.org/abs/2608.22092)（2026-08预印本，**未核实顶会接收**）已明确学习同步反事实rollout的动作差并去除共同成分。更早的 [Value Equivalence Principle](https://papers.neurips.cc/paper_files/paper/2020/hash/3bb585ea00014b0e3ebe4c6dd165a358-Abstract.html) 和 [Contrastive Value Learning，CoRL 2023](https://proceedings.mlr.press/v229/mazoure23a.html) 也覆盖决策充分模型。**“成对动作差”“价值等价”本身不是我们的新颖点。** CQM作者实现/许可本轮未核实，不复制其代码。

### 我们拟改动（可实现提案）

用仿真训练池生成同一 `x_0,ω` 的计划A/B分支；ω为固定餐食/运动/传感噪声轨迹。不能把真实患者两段相近历史当作相同潜在状态。固定reward函数r：

```text
G_sim(A)=Σ_k γ^k r(g_sim_k(x_0,ω,A))
ΔG_sim(A,B)=G_sim(A)−G_sim(B)
ΔG_hat(A,B)=G_patient(A)−G_patient(B)
L_pair=Huber(ΔG_hat−ΔG_sim)
L_total = L_fact_Loop + λ_abs L_fact_sim + λ_pair L_pair
```

应加与risk计算无关的生理轨迹对比诊断 `Δg_k = g_k(A)−g_k(B)`，而非只追一个reward差；否则更改reward定义会失去可解释性。患者模型仍生成全血糖路径，策略仍使用RL-DITR三项目标，规划仍使用同样的模型式beam。不能拿差值模型替代全部患者模型后再称RL-DITR复现。

候选研究贡献可以聚焦**仅对可识别的基础输注干预传递计划排序信息、同时把未知的真实餐食/运动效应保留为情景不确定性**。必须证明不是从单一仿真器抄策略：仿真训练世界/验证世界/最终世界分离；同样给其他被比较版本相同仿真事实样本，才隔离配对信息的贡献。当前不重训已有FQL/ReBRAC，因此它们只能标“旧数据合同参考”，不能把新增仿真监督的我方成绩直接写成算法公平胜出。

### 消融与否证

B0 H1患者模型；B1 等量独立仿真事实样本；B2 同样样本预算的配对差监督；B3 将A/B外生扰动独立打乱（验证共同扰动抵消机制）；B4 不做域混合仅sim训练。若B2不优于B1，不能声称反事实目标贡献；若B2只在训练虚拟人/固定餐食有效，应归为仿真记忆/域适配，不是泛化因果控制。

诊断：配对计划排序正确率、不同幅度/时段的Δg误差、风险差误差、held-out仿真虚拟人闭环性能、Loop事实RMSE变化、模型收益与真实仿真收益差。只训练seed260915意味着不能声称跨训练seed稳健；可做配对情景bootstrap，但不是seed方差的替代。

### 不能越过的识别限制

仿真器是公开研究工具，不是真实人体反事实oracle。Loop的未记录餐食、运动、胰岛素在体量等可能残留混杂。即使仿真配对全部通过，也只能得到仿真任务候选；不证明真实患者基础率可安全优化。动作连续保持U/h且必须保留原值/转换版本，不为生成配对而量化成注射剂量。

## 5. 为什么不优先采用其他看似容易的改动

- 把ReBRAC＋患模打分称作RL-DITR：主体不符，放弃。
- 加单调剂量损失：没有控制未来共同干预/时间延迟的真值就强制方向，可能只是让验收图变好看。
- 只换flow actor或加ensemble惩罚：已有大量工作，未隔离患者模型因果/展开问题；可作为工程手段，不能独立宣称实质创新。
- 用PWM直接对患者模型反向传播动作梯度：当剂量敏感性本身失真时，可能更有效地利用错误模型；先做动作效应与计划排序校验。
- 用BECAUSE结构mask声称去除了隐藏混杂：本任务没有满足其结构/覆盖/稳定性假设的证据，代码亦不可核实。
- 把ADM-v2历史锚点分歧直接叫“可信医疗置信度”：锚点信息量不同、可能共同偏差。需要独立校准与coverage测试，不能由分歧小推出可信。

## 6. 推荐执行次序与可训练交付

1. **B0**：先完整跑通修正后的RL-DITR（患者模型、非零三项策略目标、有限真实rollout、beam规划、独立公开仿真闭环）；只seed260915。报告policy-only与policy+planning的差异，证明规划实际起作用。
2. **H1单一主改动**：保持reward、策略目标、评估情景/预算不变，改变fT计算图并对有效prefix监督。先短烟测验证“后一步不读取前一步预测latent”和未来观测不进入推理；再实际训练。
3. **同等预算机制消融**：先A0/A1/A2，再根据证据决定是否值得做全path-risk版本。不得只挑有利结果汇报。
4. 只有动作响应仍不可信且公开仿真配对接口得到验证后，进入H2；保留失败并明确新增数据合同。

最低合理的研究判断是：完整方法在冻结仿真合同下能稳定完成控制，主要指标相对基底有可解释改善，关键风险不明显恶化，优势能通过机制消融定位。门槛可以不要求所有局部扰动满足一条强制单调比例；但不能用仅调宽门槛代替完整链路和实际控制结果。

**最终推荐：先做H1；H2为有明确数据前提的后续路线。当前证据支持“有文献依据的实质模型式改造”，不支持提前保证论文级新颖性或训练必然成功。** 若用户要求确定的非增量原创结论，必须等与ADM/MAC等近邻的机制区别和实验结果一起审查，不能靠命名实现。

## 7. 首轮实测后的近邻复查（2026-09-16）

H01改善短时预测，却仍有长期动作排序误差，并在28个共同历史上偏向策略候选上界；早期/最终策略的差异还伴随候选范围变化。因此不能把闭环差距全部解释为患者模型更准确。H02/H03先隔离同数据事实监督与配对目标，不继续同时堆新模块。

- [CQM全文第6节](https://arxiv.org/html/2608.22092v1#S6)：已覆盖配对分支、共同项抵消及动作排序；其实验限于有限动作原型、短时线性奖励。配对目标本身不能算本项目原创。连续长路径、绝对低糖暴露与闭环控制是否形成独立贡献，仍待证明。预印本身份不变。

## 8. 延迟回报策略目标消融（2026-09-16，H05/R08）

### 为什么改目标

H04增加一轮原目标策略训练后，开发1小时规划TIR下界80.73%、1/12提前终止；C01继承原策略为90.80%、0失败。R07同预算额外轮次为85.98%，也低于H02的91.07%。在225位训练患者895个固定起点上，想象项梯度范数仅为行为联合项的约0.04%；这是一项固定抽样诊断，不能单凭它保证新目标有效。4小时规划中C01/H04保持完整轨迹，而H02/R07仍大量高糖终止，说明结构和策略应分开评价。

### 近期依据及贡献边界

- [RLOO，ACL 2024](https://aclanthology.org/2024.acl-long.662/) 使用同一条件下多条独立采样轨迹的leave-one-out基线，降低REINFORCE方差；其自身也注明该估计器有更早来源。这里借用数学估计方法，不将语言模型任务结果当成胰岛素控制证据，也不称其为本项目原创。
- [TD-M(PC)²，2025预印本](https://arxiv.org/abs/2502.03550) 用相对行为策略的KL约束处理模型规划与策略失配。这里采用固定继承策略的软惩罚，不是复现其完整算法，也没有硬约束保证；本轮只核验预印本身份。
- [TD-MPC2官方实现](https://github.com/nicklashansen/tdmpc2/blob/main/tdmpc2/tdmpc2.py) 和 [DreamerV3官方实现](https://github.com/danijar/dreamerv3/blob/main/dreamerv3/agent.py) 分别提供价值尺度及回报/优势归一化的实现依据。读取日期2026-09-16、未固定仓库commit；本轮不照搬它们的损失，不把DreamerV3描述为默认纯路径导数。

### 当前实施合同

对每个原Loop历史采样4条独立4小时轨迹，每条含3个80分钟恒定动作块。原status形状、γ及连续截断高斯均不变。J_i=Σ γ^t r_t；D_i=Σ_blocks(logπ−logπ_ref)；Z_i=J_i−1·D_i；A_i=Z_i−mean(Z_j,j≠i)；L=−mean(stopgrad(A_i)·Σ_blocks logπ_i)。冻结患者模型和初始化策略π_ref，更新当前π。有限4小时目标不加V尾端；原V头及评测规划保留。

H05以C01开始，R08以H02原完整策略开始，均不继承H04/R07额外轮次；batch256、Adam lr0.001、weight_decay0.0001、完整225人/1,653,421起点、1 epoch、seed260915。最终epoch预先指定，不按开发控制挑checkpoint。新增阶段用轨迹KL替代直接历史动作NLL，全量历史仍作为起点，既有完整数据预训练保留。块策略只是每5分钟闭环重规划的代理目标，必须另做独立控制评测。

### 数学与实现检查

精确枚举两动作分布验证无KL和有KL时估计梯度与解析梯度一致；公共回报平移不变；患者与参考策略无梯度。实际128历史×4路径检查通过。实际256批量BF16初次暴露Torch2.0 autocast缓存no-grad采样权重导致log概率断梯度；改为与原imagine一致的有梯度前向采样后detach，三次实际更新验证通过，烟测权重全部丢弃。原始失败及修复记录在checks/delayed_policy_amp_integration.json。

以上是有依据的目标消融。即使控制提高，也不能只凭RLOO、KL、卷积组合声称非incremental原创；仍须与最近邻机制、消融和独立结果联合审查。
